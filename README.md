# PolyData Documentation

Documentation site for PolyData built with [Mintlify](https://mintlify.com).

## Local development

Install Mintlify CLI:

```bash
npm install -g mintlify
```

Run docs locally:

```bash
mintlify dev
```

Opens at http://localhost:3000

## Deployment

Mintlify auto-deploys on push to `main`. Configure deployment at [dashboard.mintlify.com](https://dashboard.mintlify.com).

Custom domain: `docs.polydata.live` → CNAME to Mintlify's hosting.
